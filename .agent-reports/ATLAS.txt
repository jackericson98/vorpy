Canonical interface replay boundary-generator diagnosis
========================================================

Published 2026-10-20. Status: BLOCKED at the PRISM/VECTOR replay seam; no
ATLAS correction was applied.

Bounded reproducer (no molecular solve): construct the existing synthetic AW
network from `vorpy.tests.network.test_views._network(scheme='aw')`, attach a
four-atom `System`, set
`generator_system_indices=(0, 1, 2, 3, None)`, stable IDs
`system:0..system:3,boundary:4`, one explicit `BoundaryGenerator`, and
`source_network_id='producer:aw-interface'`. Attach real `Group` A/B and an
`Interface`, then call VECTOR's `write_checkpoint`. Replaying with the public
CLI boundary:

    vorpy --load-network aw_checkpoint.vpy -g "c A" -g "c B" -i

fails before view construction with:

    ArchiveError: Recovery source contains non-source boundary generators

The exact same network saved through the legacy v3 serializer reloads and
retains its boundary metadata. The canonical container's `network-v3` payload
also reloads losslessly. Therefore this is not stale evidence (source bytes,
SHA-256, payload digest, and dependency digest validate), not geometry
reconstruction, and not generator-ID corruption.

Cause: C plus a CLI adaptation error. `Checkpoint._load_canonical_checkpoint`
selects the best available network payload; interface-only output can contain
only a group/interface-scoped network. `_run_archive_interface_recovery` then
passes that scoped network to `validate_network_source`. That validator is
deliberately a full ordered molecular-source check: it requires every local
generator to map to the source PDB and rejects `None` boundary memberships.
An AW interface network legitimately has a local subset and virtual boundary
generators, so the validator is checking the wrong identity boundary. No
validation should be weakened.

Separate metadata gap: VECTOR's `_network_payload` fallback
`network-geometry` payload serializes only tables and settings. It omits
boundary indices/generator records, local-to-source IDs, and solvent/context
membership. Such a payload is correctly not accepted as replayable by the
current canonical loader, but it cannot support lossless boundary replay until
VECTOR preserves those fields or marks the scope non-replayable explicitly.

Original/reloaded comparison on the v3 canonical payload:

* generator IDs: equal (`system:0..system:3,boundary:4`);
* local/source membership: equal (`0,1,2,3,None`);
* boundary count/identity: equal (one, `boundary:4`);
* solvent/context: equal (`FULL_SOLVENT`, no solvent rows in this fixture);
* ordered A/B selection: equal (`(0,)` -> `(1,)`);
* feature incidence: equal (surface 0 and all retained incidence);
* source-network lineage: equal (`producer:aw-interface`);
* Results: no typed Results were attached, so both archives correctly contain
  zero Result records; network state remains `PARTIAL`.

Handoffs
--------

PRISM must either load a full-system source network before interface replay,
or add a canonical source-free replay adapter that validates the embedded
source atom universe plus the scoped network's explicit boundary/context
identity. It must not call the full-system `validate_network_source` on a
scoped interface payload and must not build geometry. If no compatible full
source payload exists, fail closed with a scope/identity diagnostic.

VECTOR must include a replayable system/source network state alongside scoped
interface states in a shared checkpoint, and must preserve boundary and
solvent/context metadata in any partial geometry payload. NEXUSA should hold
canonical interface replay acceptance until those handoffs land. FORGE has no
geometry defect or requested change from this reproducer.
