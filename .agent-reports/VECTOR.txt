## 2026-10-19 classic geometry-log restoration

Historical evidence was checked in Git history, the committed legacy writers,
parsers/tests, and local generated samples. The verified classic file names are
`aw_logs.csv`, `pow_logs.csv`, and `prm_logs.csv`, selected from the network
`net_type`. The section order is build information, group information, Atoms,
Surfaces, Edges, and Vertices. Records retain atom/cell identity, coordinates,
radii, contacts/neighbors, surface area and volume contributions, edge/vertex
geometry, and supported curvature fields.

Local historical samples exist at `output/cambrin_20/a_55/aw_logs.csv`,
`output/cambrin_21/a_55/pow_logs.csv`, `output/cambrin_22/a_55/prm_logs.csv`,
and the 1BNA interface output. The older samples have verified headers of 36
atom fields, 12 surface fields, 5 edge fields, and 9 vertex fields. The current
committed sectioned writer is a header-compatible superset: its current output
is 47/17/17/11 fields after the curvature additions and `LogWriter` ordering.
`vorpy.src.inputs.logs` and the header-driven readers accept both layouts. A
byte-for-byte historical layout was not fabricated; exact compatibility with
consumers that use positional offsets remains unverified.

Implementation status: classic interface logs are now explicitly emitted by
the default interface bundle as `<net_type>_logs.csv`; canonical typed Results
remain separate as `logs.csv`, `logs.compact.csv`, and
`logs.provenance.json`. The classic writer preserves `Complete Cell?` rows for
active incomplete cells. Missing interface curvature is blank, while present
numeric values and legacy contact/geometry fields are retained. Archive reload
can export the classic log without `Network.build()`.

Compact-export benchmark (bounded synthetic 106-row Results case, 2,000
unresolved simplex identifiers, 7 warm repeats; no molecular solve): legacy
canonical CSV median 101.2 ms, 1,097,266 bytes, 1 file; compact bundle median
55.7 ms, 1,139,691 bytes including the unchanged legacy compatibility CSV and
3 files. The compact CSV plus provenance sidecar are 42,425 bytes, a 96.1%
reduction versus the legacy CSV. Compact artifact encoding/JSON/filesystem
stages were approximately 6.5/2.9/1.3 ms; memory was not measured.

Validation: 95 focused tests passed in 7.64 s across compact provenance,
output layout/caching/presets, source-view exports, and typed interface archive
reload. Added bounded checks cover default classic output, historical header
fields, incomplete cells, blank unavailable curvature, and reload-to-classic
export. No real 1BNA, EDTA, GROMACS, or full molecular solve was run.

Handoff: NEXUSA should treat the two output categories as distinct and keep
the positional-reader compatibility question open before declaring classic
schema certification. ATLAS compact provenance and GAUSS scientific semantics
were not redefined by this exporter change.

## 2026-10-20 live canonical output integration

The frozen NEXUSA layout, PRISM `ExportPlan`, ATLAS checkpoint container/update
API, and GAUSS status semantics are now connected at the live writer boundary.
Normalized exports create one root source copy, `system/`, `groups/`,
`interfaces/`, and `<system>_checkpoint.vpy`. Interface-only exports create
`groups/A/A.pdb`, `groups/B/B.pdb`, and an `interface_atoms.pdb` union of the
validated direct A/B contact atoms without solving standalone group networks.
Canonical interface defaults no longer emit classic `*_logs.csv`, `logs.csv`,
or provenance sidecars. `results`, `provenance`, and `legacy_results` remain
explicit component dispatches; direct legacy `export_preset` callers retain
their compatibility behavior. Canonical group summaries use `group_info.txt`;
legacy readers and legacy directories retain `network_info.txt`.

Bounded synthetic interface matrix (`_contract_case`, 5 network generators,
4 surfaces/edges/vertices; no molecular solve):

The file sets are cumulative. Large/all curvature, topology, and shell
components are represented as explicit `NOT_SUPPORTED` statuses in

product; no scientific zero or fabricated mesh is emitted. The synthetic
fixture cannot satisfy v3 archive index closure, so the checkpoint stores a
lossless partial geometry-table payload; valid solved networks use the
existing v3 bytes as the opaque checkpoint payload.
