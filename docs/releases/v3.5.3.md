# VorPy 3.5.3 release candidate

Status: provisional; not published.

## Release scope

3.5.3 is a patch-level release candidate. The validated changes preserve the
existing public AW/POW/PRM APIs and archive formats while making profile/export
dependencies explicit and reducing package data to a small synthetic example.
The removal of bundled research structures is intentional; callers must pass
their own input paths.

Install after publication:

```bash
python -m pip install vorpy3==3.5.3
conda install -c conda-forge vorpy3=3.5.3
```

The Conda command is prospective until the feedstock is updated.

## Export profiles

`--profile full -e small` is the supported bundled analysis export. Geometry-only
profiles may request geometry components explicitly, or use `-e none` for a
checkpoint-only run. System/group `small`, `medium`, `large`, and `all`
presets include analysis-dependent summaries and are rejected with an
actionable message when used with `--profile geometry`; the checkpoint remains
available. Interface compact summaries remain supported where their writer
contract is geometry/provenance based.

## Validation summary

The final frozen-candidate matrix collected 369 tests and completed with 368
passed, one explicit missing-`1AAY_no_sol.pdb` skip, and no failures. A
bounded EDTA subprocess regression passed (one test), the headless Workbench
selection passed (89 tests), and the compact cache-only compatibility
selection passed (40 tests). Separate archive selections passed; three
legacy-recovery tests remain skipped because the verified 1BNA checkpoint is
not present in this checkout. Missing 2KAI molecular-surface fixtures remain
unresolved and are not counted as passes.

both passed `twine check` and contain only the redistributable `HO_cube.pdb`
example among structure data:
