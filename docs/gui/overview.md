# Graphical User Interface

The VorPy GUI provides an interactive environment for configuring, solving, analyzing, and exporting molecular Voronoi calculations.

A typical workflow is:
1. load a structure,
2. inspect system information,
3. adjust radii or masses if required,
4. create one or more groups,
5. define molecular selections,
6. configure build settings,
7. configure exports,
8. run an individual group or the complete system,
9. inspect generated outputs.

Major GUI areas include system information, input/output paths, radii/mass adjustments, groups, group selections, build settings, exports, run controls, and help.

The GUI is best for interactive setup and parameter exploration; the CLI is generally preferable for batch processing, large calculations, and repeated scripted analyses.
