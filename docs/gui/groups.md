# Groups in the GUI

Groups are independently configured molecular selections. Each group can maintain its own name, selection, build settings, and export configuration.

Selections can be based on atom, residue, chain, or molecule indices; protein, ligand, DNA, or RNA classes; and structural identities as that functionality expands.

Users can run one group independently for testing or execute all configured groups as part of a complete system workflow.
