# Contributing

Contributions, bug reports, validation cases, and documentation improvements are welcome.

```bash
git clone https://github.com/jackericson98/vorpy.git
cd vorpy
pip install -e .
pytest -q
```

Changes affecting partitioning algorithms, radii handling, surface geometry, curvature, interfaces, or numerical tolerances should include representative validation whenever possible.
