# CLI Selections

CLI selections define which molecular components belong to a group. Current capabilities include index-based selections and general molecular classes such as protein, ligand, DNA, and RNA.

Identity-based selection is being expanded for identifiers such as `chain A` and `THY 124`.

See [Molecular Selections](../molecular_analysis/selections.md).
